Quick Look inspector for macOS

Glimt

Open a file in Glimt to inspect source code, Markdown or structured data. When Finder selects Glimt, press Space to see the same inspection in Quick Look.

Download View on GitHub

Requires macOS 15 or later · Open source · Version 1.0

One inspector instead of many plugins

Readable, honest previews for the files you work with.

Glimt uses the filename, file type and up to 64 KiB of content to choose how to inspect a regular file. It then reads within the selected inspector’s limits and shows a diagnostic when a view is unavailable.

Structured data

Tree, Pretty or Raw.

JSON, YAML and XML offer a collapsible tree, formatted text when available, and original text in Raw. YAML files with multiple documents show each document separately in Tree. Invalid input keeps Raw available with a diagnostic. Property lists open in a typed Tree by default. Raw shows original text for text property lists and a bounded hexadecimal view of the original bytes for binary property lists. JSON Lines (.jsonl and .ndjson) opens in Tree with one JSON value per record and keeps the source available in Raw.

The original file is never changed. Every view is presentation only.

Settings

Tune it once, see it live.

Adjust appearance, fonts, wrapping and limits in Settings, then configure each format’s views and default in Formats & Views. The preview beside the settings updates as you change them.

VCS Support in Advanced settings is off by default. When enabled, Glimt can mark changed lines for files in local Git or Subversion working copies after the preview opens. Repository access is read-only.

Inquiry shows how Glimt reads any file you drop on it.

Supported formats

From plain text to property lists.

These families use Glimt’s bounded engine. Individual syntax, views and format coverage have documented limits; Finder may select another provider. See the format coverage and limitations.

</> Source code Syntax colours for dozens of languages, build files and configuration.

Source shows syntax colours and line numbers, Raw shows the original text, and Hex shows the underlying bytes. Code, templates and build scripts are only ever displayed.

  • Recognises files such as Makefile, Dockerfile, Jenkinsfile and CMakeLists.txt by name.
  • Reads the contents when an extension is shared, for example to tell Verilog from other .v files or Transact-SQL from other SQL.
  • Optional VCS Support marks changed lines in local Git and Subversion working copies.
  • Never compiles, runs or evaluates anything, and never loads included files.

# Markdown Rendered documents with math and diagrams, drawn offline.

Rendered shows Markdown the way it reads, and Source shows the Markdown text itself. Everything is drawn locally, without network access.

  • Tables, task lists, footnotes and syntax-coloured code blocks.
  • Math and Mermaid diagrams render offline. When one cannot render, its source stays visible.
  • Links to headings jump within the preview. External links stay inert, and remote images show as alt text.
  • Also opens TextBundle packages, R Markdown and standalone Mermaid files.

{ } Structured data Trees, tables and summaries for data, archives and certificates.

Tree lets you browse the structure, Pretty shows formatted text when available, and Raw keeps the original. Invalid input keeps Raw available with a diagnostic.

  • JSON, YAML, XML and property lists, including multi-document YAML and JSON Lines with one record per line.
  • Table lays out repeated XML records and the contents of ZIP and TAR archives without extracting them.
  • Readable summaries of certificates, SSH and PEM keys, JWTs, SBOMs and SQLite schemas. JWT claims are labelled unverified.
  • Xcode projects, schemes, string catalogs, test plans and privacy manifests.
  • Strictly read-only: nothing is imported, extracted, decrypted, queried or verified.

Aa Text and tables Plain text, CSV, logs and diffs, laid out for reading.

Glimt detects the encoding and line endings of plain text, and opens tabular text, logs and patches in views made for them.

  • CSV and TSV open in Table with the first record as headers, including quoted fields that span lines and rows of different lengths.
  • Syslog, JSON logs, logfmt and web server access logs become rows of timestamp, severity and message, with nested fields in Tree.
  • Diff shows changed files and hunks with added, removed and context lines, without applying the patch.
  • Raw always keeps the original text, including lines Glimt does not recognise.

01

Local and offline

Glimt never uses the network. Remote images and links stay inert text.

02

Never executes content

Rendering is native. Glimt never runs scripts or external tools and never loads file content in a browser engine.

03

Bounded by design

Every preview reads a bounded amount of the file and has a deadline. Large or unsupported files fall back to a readable view.

Get Glimt

Install Glimt.

Builds are published on GitHub Releases. They are not notarized yet, so macOS asks you to approve the first launch. Which Quick Look provider Finder uses for a file type can be affected by other installed apps.

See the README for known issues, uninstalling, and building from source.

  1. 1
    Download

    Get Glimt-latest-macOS.zip, unzip it and move Glimt.app to Applications.

  2. 2
    Approve the first launch

    Open Glimt, then choose Open Anyway in System Settings › Privacy & Security.

  3. 3
    Enable Quick Look

    Check that Glimt is on under System Settings › General › Login Items & Extensions › Quick Look, then press Space on a file in Finder.

Inspect files safely.

Glimt is free and open source for macOS 15 and later.
